# Netflix Catalog Analysis | Power BI Dashboard

## 📊 Overview
Interactive dashboard analyzing 8,807 Netflix titles to uncover content trends, geographic distribution, and release patterns.

## 🚀 Live Preview
![Dashboard](dashboard_preview.png)

## 📈 Key Insights
- **6,131 Movies** vs **2,676 TV Shows** | 70/30 split
- **United States** leads production with 3,244 titles
- **Peak content release** between 2018-2020
- **Global catalog** spanning 100+ countries

## 🛠️ Tech Stack
- **Power BI Desktop**
- **DAX** for calculated measures
- **Data Modeling & ETL**
